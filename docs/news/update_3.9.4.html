Оновлення корпоративного сервісу «Арт-Офіс» до версії 3.9.4

2026-10-02 /
Сервіс «Арт‑Офіс»

Шановні користувачі!

Повідомляємо, що проведено оновлення сервісу обміну електронними документами «Арт‑Офіс»:

Зміни у версії 3.9.4:

  • Робота з КЕП:
    • Додано підтримку ключів monoКЕП через API
    • Оновлено ланцюжок сертифікатів КНЕДП ТОВ «Вчасно Сервіс»
    • Оновлено ланцюжок сертифікатів КНЕДП АЦСК АТ КБ «ПриватБанк»
    • Додано та оновлено ланцюжки кореневих сертифікатів КНЕДП ДП «Дія», КНЕДП ДП «УСС» та КНЕДП «АЦСК ринку електричної енергії»
    • Оновлено ланцюжок сертифікатів КНЕДП «eSign» ТОВ «Ілайф» та сховище сертифікатів
    • Для хмарних ключів monoКЕП реалізовано примусовий перехід на формат підпису CAdES-X Long
    • Оновлено ланцюжок сертифікатів КНЕДП АТ «ТАСКОМБАНК»
  • Безпека та криптографія:
    • Оновлено COM-криптобібліотеку до версії 2.8.45.4527
    • Оновлено JavaScript криптобібліотеку до версії ArtLib.2.8.45.4532.script
    • Оновлено WebCryptoService до версії 1.1.18.4526
    • Оновлено .NET Framework до версії 4.8.0
    • Оновлено NuGet пакети
    • Доопрацьовано налаштування заголовків безпеки та конфігурацію домену Masterkey
  • Інтерфейс та авторизація:
    • Оновлено оформлення сторінки входу через Email/Active Directory
    • Оновлено дизайн випадаючого списку на сторінках авторизації та вибору ролі
    • Оновлено футер на сторінці авторизації хмарним ключем
    • Оновлено дизайн головної сторінки, сторінки авторизації та вибору ролі
    • Оновлено дизайн сторінки помилки при повторному відкритті посилання на підтвердження email
  • Робота з документами:
    • Реалізовано можливість виводити список "Доступ на перегляд" в алфавітному порядку при створенні документа для ролі "Оператор внутрішніх документів"
    • Реалізовано можливість збереження кастомних маршрутів обробки документів
    • Доопрацьовано модальне вікно «Версії документа» в мобільному режимі для ролі "Адміністратор внутрішніх документів"
    • Доопрацьовано розміри елементів та відступи у вікні створення ЗЕД-документа з шерінгом
    • Реалізовано механізм контролю кількості невдалих спроб відправки нотифікацій для ВЕД-документів та ФінМон з обмеженням подальших спроб після досягнення встановленого ліміту
  • Модуль інтеграції та генерації документів з ERP Workday:
    • Змінено піктограму для дії «Запит на ручне підписання»
  • Виправлено помилки:
    • Виправлено відображення причини відхилення документа в режимі плитки для ролей "Оператор внутрішніх документів" та "Адміністратор внутрішніх документів"
    • Виправлено створення маршруту обробки для організації-супутника з основною ліцензією ВЕД
    • Виправлено відображення назви випадаючого списку при створенні документа з кастомним маршрутом
    • Виправлено відображення тексту сертифіката у вікні вибору ключа з апаратного або хмарного сховища
    • Виправлено помилку при створенні одностороннього документа через відсутність даних підписанта
    • Виправлено відображення підпису при підписанні одного документа у різних вкладках
    • Виправлено відображення назви КНЕДП «Україна» при авторизації ключем ТОВ «ЦСК Україна»
